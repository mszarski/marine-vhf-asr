How to mark a clip
  • Listen, then fix the draft so it says exactly what was said. Capitals and punctuation don't matter.
  • Write numbers the way they were spoken: one four if they said "one four", fourteen if they said "fourteen".
  • Put [?] for a word you can't make out. Don't guess.
  • Select a vessel name and press Vessel name to wrap it in braces, like {dorothy j}. This is how name accuracy gets scored.
  • If two people talk in one clip, just write it all in order.
  • No speech for static, tones or silence. Can't tell when someone is talking but you can't write most of it.
  • Keys: Ctrl+Enter save and next, Ctrl+Space replay.
